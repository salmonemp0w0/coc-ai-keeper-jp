# 要件メモ(v0)

コーディングエージェント(Claude Code / Codex)をキーパー役にしてクトゥルフ神話TRPGを
ソロプレイするための、最小構成のスキャフォールドの要件メモです。

## スコープ(v0)

- ソロプレイ、1探索者を想定。
- キーパー役はチャットベースのコーディングエージェント(Claude Code / Codex)。
- 既定ルールは第6版・日本語寄り(カジュアル運用)。第7版は任意プロファイルとして選択可能。
- 判定(ダイスロール)はエージェントではなく `scripts/roll.py` が実行する
  (LLMによる出目の捏造を防ぐため)。
- セッションの状態は `sessions/<session-id>/state.json` に、
  プレイログは同フォルダの `log.md` に保存する。

## 非スコープ(v0)

- ルールブック本文・市販シナリオ本文の格納・生成。
- マルチプレイ(複数プレイヤー)対応。
- Web UIやGUIクライアント。
- 自動シナリオ生成機能。
- 詳細な戦闘・呪文・SAN喪失表などのルール実装(ユーザーの手元資料に委ねる)。

## 設計方針

- **判定の実行はコードに任せる**: LLMは判定の必要性・状況描写を担当し、
  実際の乱数生成は `scripts/roll.py` に一任する。
- **ルール本文を含めない**: プロンプト・ドキュメントには判定の「考え方」の要約のみを書き、
  Chaosiumのルールブックや市販シナリオの文章を複製・引用しない。
- **状態はファイルで永続化**: セッションの状態(探索者情報、進行状況)は
  JSON(`state.json`)、プレイの記録はMarkdown(`log.md`)に分離して保存する。
- **版の切り替えは差し替え可能に**: `prompts/profiles/` 以下にルール版ごとの
  短いガイドを分離し、既定(6e-jp)と任意(7e)を切り替えられるようにする。
