# coc-keeper

Grok CLI 用のキーパースキルです。手順の正本は `skills/coc-keeper/SKILL.md` で、内容はそこに揃えます。
リポジトリ直下の `skills/` は Grok から自動では読まれないため、同じ手順をこのファイルに置いています。

クトゥルフ神話TRPGのソロセッションを、キーパー役として進行するためのスキルです。
ルールブック本文・市販シナリオ本文は扱いません。

## 使うタイミング

- ユーザーがクトゥルフ神話TRPGのソロセッションを開始・再開したいとき。
- セッション中に技能判定・SANチェックなど、ダイスロールが必要になったとき。
- セッションの状態(探索者情報、進行状況)を保存・更新する必要があるとき。

## 手順

1. `prompts/keeper-system.md` を読み、キーパーとしての振る舞い(トーン、ネタバレ禁止、
   判定は必ずスクリプト経由、など)を確認する。
2. 既定ルールは `prompts/profiles/6e-jp.md`。ユーザーが第7版を希望した場合のみ
   `prompts/profiles/7e.md` に切り替える。
3. 対象セッションの `sessions/<session-id>/state.json` を読み込み、現在の状況を把握する。
   セッションIDが不明であればユーザーに確認する。存在しなければ `sessions/example/` を
   雛形として新規作成する。
4. 判定が必要な場面では、状況をユーザーに一言伝えてから
   `python scripts/roll.py check --skill <技能値>` (または7eなら `--edition 7e` 付き)を
   実行し、その結果に基づいて描写する。出目を自分で決めてはいけない。
5. 状態が変化したら `state.json` を更新し、出来事の要点を `log.md` に追記する。

## 注意事項

- ルールブックの数値表・チャート、市販シナリオの文章を生成・引用しない。
- 探索者がまだ知り得ない情報を先回りして明かさない。
- 詳細なルール適用(SAN喪失表、戦闘ダメージ表など)が必要な場面では、
  ユーザーに正規ルールブックの参照を促す。
- 判定コマンドは bash ツールで実行し、出目を書く前に必ずその実行結果を得ること。
- `state.json` と `log.md` は read_file で読み、search_replace(または write)で更新すること。
