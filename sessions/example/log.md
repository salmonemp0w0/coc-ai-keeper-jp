# セッションログ: example

このファイルはプレイログの雛形です。市販シナリオの本文は書かず、
実際に卓で起きた出来事・判定結果・要点のみを記録してください。

## フォーマット例

```
## 2026-01-01 セッション1

- 探索者「〇〇」が××に到着。
- 【判定】目星 60 → 出目 23 → success (scripts/roll.py check --skill 60)
- 出来事の要点を簡潔に記述。
- SANチェック実施: 出目 45 → failure(詳細な喪失量はルールブックに従い state.json に反映)
```
