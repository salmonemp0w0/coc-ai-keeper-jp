# 判定ガイド: 第7版(7e)スタブ

第7版の判定を使いたい場合の、概念だけを示す短いスタブです。
ルール本文・具体的な数値表は含みません。詳細は正規ルールブックを参照してください。

## 概念のみ

- **難易度の段階**: 通常成功(regular)、より厳しい困難成功(hard)、
  さらに厳しい極限成功(extreme)という段階がある、という概念のみ扱います。
  具体的な閾値の計算式(技能値の何分の1か等)はここでは記載しません。
- **ボーナスダイス/ペナルティダイス**: 状況が有利なら追加の十の位ダイスから
  有利な方を採用、不利なら不利な方を採用する、という概念のみ扱います。
  `scripts/roll.py check --edition 7e --bonus N` / `--penalty N` で
  この概念を模した処理を行います。
- **プッシュロール(pushed roll)**: 失敗した判定を、リスクを負って
  もう一度振り直せる、という概念のみ扱います。具体的な適用条件・
  リスクの内容は卓の採用ルールに従ってください。

## このリポジトリでの出力ラベル

- `scripts/roll.py check --edition 7e` を使うと、結果ラベルとして
  `regular` / `hard` / `extreme` / `fail` を返します
  (成功度の判定は出目と技能値の単純な比較によるものです)。
- 難易度の閾値計算式そのものはルールブックの数値ルールに依存するため、
  本リポジトリでは固定の計算式を「公式ルールの再掲」として書き下しません。
  `scripts/roll.py` 内の実装コメントを確認の上、必要に応じて調整してください。

## このガイドでやらないこと

- 技能一覧・初期値の一覧化
- 戦闘・回避・ダメージの詳細ルール
- SAN・狂気・呪文の数値データ
